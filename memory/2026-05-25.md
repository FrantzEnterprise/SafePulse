## V0.5.7 — Mobile Scroll Fixes for All Modals (Commits after compaction)
- **Problem**: User reported Instructions modal popup on mobile does not scroll and cuts off text at bottom
- **Root cause**: `overflow-hidden` on backdrop + `max-h-[90%]` on card — card height constrained to 90% of viewport, overflow-y-auto on card didn't help because backdrop blocked scrolling
- **Fix** (applied to all 5 modals):
  - Backdrop: `fixed inset-0 z-50 overflow-y-auto bg-black/50` — whole screen scrolls on mobile
  - Inner wrapper: `flex min-h-full items-center justify-center p-4` with `onClick.stopPropagation()` — centers card with padding
  - Card: no max-height, no overflow-auto on card — content fills natural height
- **Modals updated**: InstructionsModal, SymptomResultModal, ServiceLockoutModal, BatteryPopup, MapCalculatorModal
- **Indentation fix**: Removed one extra `</div>` from SymptomResultModal's return (had 4 closings for 3 opens)
- **Duplicate removal**: Removed duplicate empty `function MapCalculatorModal({})` declaration
- **Verification**: `npm run build` succeeds (clean output without regex parsing errors)
- **Deployment**: Pushed to gh-pages via /tmp/deploy-token.sh using user's GitHub token
