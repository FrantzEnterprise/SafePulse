# SafePulse

SafePulse is an OpenClaw and InstantlyClaw compatible safe-service diagnostic skill.

## Features
- Customer self-triage
- Technician-ready reports
- Failure-risk prediction
- Feedback tracking
- Safe troubleshooting guidance

## Installation
1. Copy the `safepulse` folder into your OpenClaw skills directory.
2. Enable the skill in your OpenClaw configuration.
3. Configure messaging or web integrations as needed.

## Security
This skill intentionally blocks:
- Bypass instructions
- Drill points
- Forced-entry guidance
- Manipulation procedures
